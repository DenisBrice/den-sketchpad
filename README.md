# Den Sketchpad

A small offline sketch DAW for iPad (Web Audio, installable from Safari with Share > Add to Home Screen).
Save sketches as `.sketch.zip` to Dropbox and open them in REAPER with `Den_Sketchpad_Import_v0.1.lua`.

REAPER scripts are in `reaper/` (newest: `Den_Sketchpad_Export_v0.1.5.lua` and `Den_Sketchpad_Import_v0.5.lua`, which carry audio, MIDI notes, regions and markers both ways).
